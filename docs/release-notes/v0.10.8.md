A documentation release for **Polaroica**: the README is now the extension's page, with the longer reference material split into its own files. No change to the extension itself since [0.10.7](https://github.com/leonardok/polaroica/releases/tag/v0.10.7).

## Install

Download `polaroica-0.10.8.vsix` below, then in VS Code: **Extensions** view → `…` menu → **Install from VSIX…** (or run `code --install-extension polaroica-0.10.8.vsix`). Requires VS Code 1.85 or later.

## Changed

- The [README](https://github.com/leonardok/polaroica/blob/main/README.md) reads as the extension's page: links to the site and downloads at the top, then install, what Polaroica does, the formats it reads, where to find the rest, and the known limitations.
- The Marketplace page now links to [leok.me/polaroica](https://leok.me/polaroica) and to the issue tracker.
