A packaging fix for **Polaroica**: the extension is now published by **ChimarraoTech**. Nothing else changed since [0.10.5](https://github.com/leonardok/polaroica/releases/tag/v0.10.5).

## Install

Download `polaroica-0.10.6.vsix` below, then in VS Code: **Extensions** view → `…` menu → **Install from VSIX…** (or run `code --install-extension polaroica-0.10.6.vsix`). Requires VS Code 1.85 or later.

## Upgrading from 0.10.5

The new publisher gives the extension a new ID (`ChimarraoTech.polaroica`, was `leonardok.polaroica`), so VS Code sees it as a different extension:

- **Uninstall Polaroica 0.10.5** first, or both will be installed side by side.
- Your **ratings, flags and edits are kept**: they live in the `.sidecar` folders next to your photos.
- Thumbnails are built again once, in the background. Auto-Rank options, the grid's tile size and recent export / move folders start from their defaults.
