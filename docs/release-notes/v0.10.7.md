**Polaroica 0.10.7** brings one-click **Auto** adjust, new Presence, Detail and Color tint sliders, and thumbnails built as you open albums. Changes since [0.10.6](https://github.com/leonardok/polaroica/releases/tag/v0.10.6):

## Install

Download `polaroica-0.10.7.vsix` below, then in VS Code: **Extensions** view → `…` menu → **Install from VSIX…** (or run `code --install-extension polaroica-0.10.7.vsix`). Requires VS Code 1.85 or later.

## New

- **Auto adjust**: the wand at the top of the ADJUST panel sets Exposure, Contrast, Highlights, Shadows, Whites, Blacks, Temp, Tint and Vibrance for a balanced picture. It judges brightness on faces when Auto-Rank has found them (People option), otherwise on the middle of the frame. Night scenes stay dark and snow stays bright, and colour casts are corrected part of the way. It only moves the sliders, so you can fine-tune or undo it.
- **Your own Auto correction**: **Settings › Polaroica › Auto Adjust** adds amounts of your own on top of every Auto, for example a little brighter and warmer.
- **New sliders**:
  - **Presence**: Clarity (local contrast) and Dehaze.
  - **Detail**: Sharpness (below 0 softens), Noise, Moiré and Defringe.
  - **Color**: a tint laid over the picture, with a Strength slider.

  Exports include them all.
- **Build Thumbnails Here…** (right-click an album) builds an album's thumbnails ahead of time, with or without its sub-albums.

## Changed

- Thumbnails are now built as you open albums, so adding a huge library no longer crawls all of it up front. Background building for every library is still available, but off by default (`polaroica.backgroundThumbnails`).
- **Temp** is a −100 to 100 slider again, 0 being the photo's own white balance. Kelvin values from earlier edits are converted when a photo opens.
- The ADJUST panel's Auto, Reset, Copy and Paste are icon buttons above the histogram. Pick, Reject and Auto-advance in the rating bar are icons too.
- The photo tab no longer shows the picks / rejects / to-go count or the note about where edits are saved.

## Fixed

- Thumbnails could read back wrong after VS Code quit before the cache index was saved.
