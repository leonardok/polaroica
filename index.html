Features

A darkroom next to your code.

Everything you need to get from a full memory card to a handful of keepers, built on the editor you already have open.

Libraries, local or on the NAS

Each library is a workspace folder: a local folder or an SMB share your computer can already reach. No passwords stored, offline shares clearly marked.

Fast grid & photo tabs

Justified grid with EXIF details, keyboard selection and sorting. Open any photo in its own tab with a filmstrip and ← → navigation.

Non-destructive edits

Exposure, contrast, highlights, shadows, tone curve, white balance, vibrance — drawn live with WebGL. Saved as XMP sidecars; originals are never touched.

Culling at keyboard speed

Pick P, reject X, stars 0–5, with auto-advance. Filter by flag or rating, then send rejects to the Trash in one click.

Auto-Rank

Measures focus on the subject, blown highlights and blinks, groups bursts and picks the best of each — then explains every decision.

Export & organise

Export JPEGs with your edits applied. Move photos between folders and libraries with sidecars carried along, verified copy before delete.

Auto-Rank

Shot 40 frames of the same moment? It picks the one.

Right-click an album and let every CPU core look at it. You stay in charge: your own ratings are never overwritten, and one click undoes the whole run.

  • Focus where it matters. Sharpness is measured inside the faces when there are people, so a crisp face on a blurred background wins.
  • Nobody blinks. Optional face models check eyes open, looking at the camera, smiling and natural expression.
  • Bursts become stacks. Similar shots are grouped, the best is picked, and near-ties are kept instead of rejected.
  • Runs on your machine. Models ship with the extension (Apache-2.0). Your photos are never uploaded.

Built for big libraries

Fast on a slow network share.

A local cache keeps 100,000-photo NAS libraries browsable in milliseconds.

Tiny thumbnails

~5 KB WebP thumbnails, packed per folder, built in the background from the previews cameras already embed — a 72 KB read instead of the whole file.

Every core, gently

WebAssembly codecs (mozjpeg, libwebp) on worker threads keep the editor responsive and pause while you browse.

Private by design

No account, no cloud, no telemetry of your photos. Edits and ratings live in standard XMP sidecars next to the files.

Install

Up and running in a minute.

Works in VS Code 1.85+ on Windows, macOS and Linux.

Get the extension

Download the latest .vsix from the GitHub releases, then install it:

code --install-extension polaroica-0.8.0.vsix

Add a library

Open the Photo Libraries view in the activity bar and press +. Pick a folder, or a share like \\nas\photos or smb://nas/photos.

Start culling

Click an album to open the grid. Flag with P / X, or right-click the album and choose Auto-Rank…
